# Showcase concept — one project, shared understanding

Draft for review after local acceptance; no video has been recorded or published. Suggested master: 45 seconds, Romanian voiceover, 16:9 screen recording with a separately reframed 9:16 cut. Language and distribution channel remain the user's choice, not implementation blockers.

## 45-second storyboard

| Time | Screen capture | Voiceover / caption |
|---|---|---|
| 0–5s | Start with the finished two-room house; short slow orbit, no menus | „Mobilierul tău începe cu o idee. Fă-o mai ușor de explicat.” Caption: „De la idee la un proiect clar.” |
| 5–17s | Create a bed; choose size and upholstery. Briefly show the matching material choices and a cabinet. | „Alege piesele, dimensiunile și finisajele. Vezi patul și mobilierul în 3D, într-un stil simplu și clar.” |
| 17–27s | Place the second room; align a doorway; switch from floor plan to whole-house view | „Așază camerele pe același nivel și vezi cum se leagă întregul spațiu.” Caption: „Camere conectate. Un singur nivel.” |
| 27–35s | Review facts and furniture; expand one item and use Edit; show the send action without waiting on a spinner | „Verifică piesele, materialele și detaliile înainte să trimiți cererea.” Caption: „Verifici. Corectezi. Trimiți.” |
| 35–42s | Clearly label „Perspectiva firmei”; show the same request and house in the authorized firm view | „Firma vede proiectul și cerințele, ca să poată pregăti o ofertă.” Caption: „Aceeași idee, mai ușor de înțeles.” |
| 42–45s | Current on-screen app name and one CTA | „Descoperă Cozy Home.” Client cut: „Începe proiectul tău.” Firm cut: „Solicită o demonstrație.” |

The spoken copy is designed for approximately 40–45 seconds at an assumed 120–135 words/minute, with short pauses. This is an estimate, not a recorded read-through. Record a timed take before locking the edit; allow the UI actions to finish visibly. The current UI brand is Cozy Home; do not rename it to the repository name in the video without a branding decision.

## Same footage, two alternate lengths

- **30 seconds:** 0–3 finished-house hook; 3–11 bed/material selection; 11–18 connect rooms; 18–24 summary; 24–28 firm view; 28–30 CTA. Short narration: „Transformă ideea de mobilier într-un proiect clar. Alege piesele, dimensiunile și materialele. Conectează camerele pe un singur nivel și vezi întregul spațiu. Verifică rezumatul, apoi trimite cererea. Firma vede proiectul și detaliile pentru ofertă. Descoperă Cozy Home.”
- **60 seconds:** retain the 45-second sequence; add 5 seconds showing a saved project reopened, 5 seconds demonstrating paired doorway editing/undo, and 5 seconds expanding a furniture specification in the firm view. These are demonstrations, not claims of automatic manufacturing-ready plans.

## Capture checklist

1. Use only the isolated demo database and the two-room/five-placement fixture in `house-demo-fixture.json`. Create a fresh demonstration request if its test claim was withdrawn. Use synthetic contacts, never a real customer or production account.
2. Record in the production preview after the container/browser checks pass. Warm the routes once, close notifications and developer tools, disable browser autofill, and keep the pointer still between actions. Use modest camera movement and readable UI text; do not speed up footage in a way that implies live performance.
3. Capture separate takes for furniture, floor plan, house 3D, summary and firm view. Keep the perspective switch visibly labelled. Do not expose email, full address, signed file URLs, session tokens, payment screens or admin data.
4. Add high-contrast captions, leave text clear of UI controls, and use only licensed audio. Show supplied contacts only if demonstrating the actual authorized post-claim state; it is unnecessary for this short video.
5. Record a timed voiceover and select one CTA for each audience cut. Review together before publication. Do not claim multiple floors, automated prices, guaranteed offers, real antivirus, manufacturing precision, user counts or time savings that have not been demonstrated.

## Recording readiness

Furniture, connected one-floor layout, review and authorized firm access have local implementation evidence. The script intentionally avoids showing an actual price/quote result until the chosen demo offer is prepared and verified. Final branding, aspect ratio, narration and channel are review choices; filming/editing/publication were not requested as automatic actions.
